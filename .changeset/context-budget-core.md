Agent context budgets: `with.context` and `runtime.context` fit every agent model call into a token budget with the `none`, `last`, `trim` or `summarize` strategy, never separating a tool call from its result. `with.context.history` reads a messages channel as prior conversation and appends each turn with deterministic ids, removing what was left out and keeping a running summary message. The LangChain provider fits before every call of its tool loop and caps tool results (`toolResultMaxTokens`); providers that run their own tool loop (Claude SDK, Cursor SDK, CLI, deepagents) get a fitted starting history and prompt only. Summaries use the agent's own model unless `summarize.provider` / `model` name another (`summarize.mode: extract` skips the model). The known-issues section of the system prompt gets its own cap (`issuesMaxTokens`), and memory recall is limited to half of the budget. Inside a subgraph an agent only appends to its history channel, so compaction never reaches the parent graph. Fitting is deterministic across interrupt/resume, and summaries are replay-cached. A budget that cannot be met fails the node with `ContextOverflowError` (code `CONTEXT_OVERFLOW`, not retried; `runWithPolicy` now skips retries for errors marked `retryable: false`) unless `onOverflow: warn`. Also adds `registerTokenEstimator`, the `agent.context` event, the `CONTEXT_OVER_BUDGET` / `CONTEXT_SUMMARY_FAILED` / `CONTEXT_HISTORY_READ_ONLY` run issues, `capabilities.contextMessages` and `ctx.context` for providers, an optional capabilities argument to `createScriptedProvider`, and the `CONTEXT_*` lint codes. Messages channels now ignore a removal of an id that is no longer in the channel instead of failing the run.

**What to change:** nothing for existing graphs. Context management is opt-in, and agents without `with.context` or `runtime.context` send the same prompts as before. To bound an agent, add `with.context: { maxTokens: …, strategy: trim }` (or `runtime.context` for every agent). With `strategy: summarize`, set `summarize.model` to a cheaper model if you don't want summaries written by the agent's main model. Code that relied on a messages-channel removal of a missing id throwing should check the channel itself.
