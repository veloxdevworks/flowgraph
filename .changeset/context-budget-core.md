Agent context budgets: `with.context` and `runtime.context` fit every agent model call into a token budget with the `none`, `last`, `trim` or `summarize` strategy, never separating a tool call from its result. `with.context.history` reads a messages channel as prior conversation and appends each turn with deterministic ids, removing what was left out and keeping a running summary message. The LangChain provider fits before every call of its tool loop and caps tool results (`toolResultMaxTokens`); other providers receive the fitted history as a transcript. Memory recall is limited to half of the budget. Fitting is deterministic across interrupt/resume, and summaries are replay-cached. Adds `registerTokenEstimator`, `ContextOverflowError` (not retried; `runWithPolicy` now skips retries for errors marked `retryable: false`), the `agent.context` event, the `CONTEXT_OVER_BUDGET` / `CONTEXT_SUMMARY_FAILED` / `CONTEXT_HISTORY_READ_ONLY` run issues, `capabilities.contextMessages` and `ctx.context` for providers, an optional capabilities argument to `createScriptedProvider`, and the `CONTEXT_*` lint codes. Messages channels now ignore removals of ids that are no longer present.
