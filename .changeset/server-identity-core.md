Host limits for untrusted graphs: `CompileOptions.nodePolicy` (`{ blockedTypes, blockSubgraphFiles, blockSecrets, reason }`) refuses blocked node types (including `map` inners, agent skill tools and embedded subgraphs), subgraphs loaded from files, and `secrets.*` lookups while the graph is built and run, with `NodePolicyError` (`NODE_TYPE_BLOCKED`, `SUBGRAPH_FILE_BLOCKED`, `SECRET_REFERENCE_BLOCKED`). `CompileOptions.memoryIdentity` scopes the in-process and shared `ctx.store` of graphs without `runtime.memory`, so same-name graphs of different orgs or users stay apart. New `GraphNameRegistry` interface with `createInMemoryGraphNameRegistry` (first registrant of a name within an org owns it).

The node policy also covers outbound requests and host access: `outboundHttp: { publicOnly, allowHosts?, maxRedirects? }` makes `http` and `webhook` nodes resolve each host, refuse loopback, private, link-local, CGNAT, reserved and cloud metadata addresses (IPv4, IPv6, IPv4-mapped, NAT64 and 6to4 forms) before connecting, and follow redirects by hand with the same check on every hop (`OUTBOUND_ADDRESS_BLOCKED`, `OUTBOUND_URL_BLOCKED`); `allowHosts` exempts named hosts except metadata and link-local. `blockMcp` refuses `mcpServers` and withholds the MCP hub, `blockLocalTools` refuses `localTools`, and `blockHostProbes` refuses `requires` checks (`MCP_BLOCKED`, `LOCAL_TOOLS_BLOCKED`, `HOST_PROBE_BLOCKED`), including in inline subgraphs and `map` inners. New exports `guardedFetch`, `classifyAddress` and `hostIsAllowListed`.
